# Fitxa Tècnica: Configuració de Repositori Git

## Objectiu
Documentar el procés de creació d'un repositori local i la sincronització de canvis mitjançant el flux de treball bàsic de Git a Visual Studio Code.

## Passos a seguir
1. Crear el fitxer en format Markdown a l'editor.
2. Definir l'estructura de seccions bàsiques.
3. Afegir els procediments de verificació i recursos multimèdia.
4. Executar el seguiment i registre de canvis amb Git.
